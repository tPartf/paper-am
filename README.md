# Paper AM · 论文晨读

[阅读网站](https://tpartf.github.io/paper-am/) · [写一篇笔记](https://tpartf.github.io/paper-am/#write)

## 每天怎么更新

1. 打开「写一篇笔记」，填写论文标题、原文链接、推荐理由和读后感，点 **去 GitHub 发布**。
2. GitHub 会打开已填好文件名和正文的编辑页。使用有写入权限的账号，点 **Commit changes** 并确认提交到 `gh-pages`。较长的笔记按页面提示复制、粘贴即可。
3. 等待 [GitHub Pages 构建](https://github.com/tPartf/paper-am/actions)完成，刷新网站就能看到更新。

也可以直接在 [已发布的笔记目录](https://github.com/tPartf/paper-am/tree/gh-pages/_posts) 里编辑。文件名按 `YYYY-MM-DD-短标题.md` 填写，同一天可以有多篇。模板附带 4 篇示例，首页按晨读日期展示最新一篇。

## 网站文件

GitHub Pages 从 `gh-pages` 分支的根目录发布。改笔记、样式或页面时都在这个分支提交。`main` 保留首次上线的模板。
